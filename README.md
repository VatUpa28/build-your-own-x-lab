# build-your-own-x-lab

My personal development lab, where I build projects inspired by the "Build Your Own X" repository.

It includes projects in web development, backend systems, databases, and other software engineering experiments.

The goal is to learn programming by building real systems from scratch and gradually improving my software engineering skills.

- Web Apps
- Database Projects
- Experimental Builds
- etc

## Purpose
Learn how real-world software systems work by rebuilding them from scratch with my own twist to it.
